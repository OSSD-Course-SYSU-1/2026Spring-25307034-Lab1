 运动健康数据管理应用 - 新增功能说明

 项目概述
基于华为运动健康服务 SDK 开发的健康数据管理示例应用，在原示例代码基础上新增了数据可视化、趋势分析、数据导出、健康目标管理和多设备切换等功能。

新增功能列表

1. 多设备数据源切换
- **功能描述**：管理多个设备的数据源（手机、手表、手环等），支持切换当前使用的数据源。
- **使用位置**：数据源管理页面 → 点击“📱 设备列表”
- **功能操作**：
  - 查看所有已绑定的设备
  - 切换当前数据源
  - 显示当前使用的设备
- **涉及文件**：
  - `DeviceSelector.ets` - 设备选择工具类
  - `DataSourceIndex.ets` - 数据源管理页面


2. 数据可视化（图表展示）
- **功能描述**：将健康数据（如步数、卡路里、距离）以折线图形式展示，直观查看数据变化趋势。
- **使用位置**：采样数据管理页面 → 点击“📊 查看图表”
- **技术实现**：通过 WebView 加载 Chart.js 库渲染图表
- **涉及文件**：
  - `ChartHelper.ets` - 图表工具类
  - `SamplePointIndex.ets` - 采样数据页面

 3. 周趋势分析
- **功能描述**：展示本周内每日步数、卡路里、距离的数据汇总，生成趋势报告。
- **使用位置**：采样数据管理页面 → 点击“📈 周趋势”
- **报告内容**：
  - 总步数、日均步数、最大步数、最少步数、最佳日期、有数据天数
- **涉及文件**：
  - `TrendAnalysis.ets` - 趋势分析工具类
  - `SamplePointIndex.ets` - 采样数据页面

 4. 月趋势分析
- **功能描述**：展示本月内每日健康数据汇总，生成月度趋势报告。
- **使用位置**：采样数据管理页面 → 点击“📉 月趋势”
- **涉及文件**：
  - `TrendAnalysis.ets` - 趋势分析工具类
  - `SamplePointIndex.ets` - 采样数据页面

 5. 数据导出功能
- **功能描述**：将健康数据导出为 CSV 或 JSON 格式文件，保存到手机本地。
- **使用位置**：采样数据管理页面 → 点击“💾 导出CSV”或“📄 导出JSON”
- **导出内容**：日期、步数、卡路里、距离
- **文件保存路径**：`应用文件目录/health_data.csv` 或 `.json`
- **涉及文件**：
  - `ExportUtil.ets` - 数据导出工具类
  - `SamplePointIndex.ets` - 采样数据页面

 6. 健康目标管理
- **功能描述**：设置每日健康目标（步数、卡路里、睡眠时长），达到目标时发送通知提醒。
- **使用位置**：主页面 → 点击“健康目标设置”
- **可设置项**：
  - 每日步数目标（1000-20000步）
  - 每日卡路里目标（100-1000千卡）
  - 每日睡眠目标（4-12小时）
  - 通知提醒开关
- **涉及文件**：
  - `GoalManager.ets` - 目标管理工具类
  - `GoalSettingIndex.ets` - 目标设置页面
  - `MainIndex.ets` - 主页面（添加入口）
