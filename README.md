作为大学生，我计划通过“从小处着手”的方式参与开源贡献：

文档翻译与优化
许多优秀开源项目（如 Django、Vue、React）的文档存在机翻或未及时更新的问题。我计划从校对文档和补充新手示例入手，提升英文阅读能力和技术写作能力。

解决“新手友好”类 Issue
在 GitHub 上筛选带有 good first issue 或 help wanted 标签的 Issue。这类问题通常涉及修复拼写错误、增加单元测试、优化 CSS 样式，非常适合积累 PR 经验。

参与社区活动与开源文化推广
关注开源社区（如开源社、ALC Beijing）举办的活动，尝试在校园推广开源文化，或参与非代码类的社区运营工作，理解开源协作的全流程。
