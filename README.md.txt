一、对开源项目的贡献想法

我现在想先从简单的事情开始参与开源：

1.帮忙改文档
很多开源项目的文档有翻译错误或者不够清楚，我可以帮忙校对和补充。

2.找新手能做的任务
在 GitHub 上找带“good first issue”标签的问题，这些比较适合新手做，比如改错字、加测试、调样式等。

3.参加社区活动
关注一些开源社区的活动，学习怎么和别人一起协作开发。

二、本学期学习目标

1.学会用 Git
熟练使用分支、合并、提交 PR 这些基本操作，不搞乱代码库。

2.多读项目代码
看一些优秀项目的代码结构，学习别人是怎么组织代码的。

3.写一篇总结
期末把自己参与开源的经历写下来，包括怎么找任务、怎么沟通、怎么提交代码。
